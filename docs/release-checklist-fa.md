# چک‌لیست انتشار در راست‌چین

این فایل مواردی را که به تصمیم انسانی، حساب فروشنده یا سرویس بیرونی نیاز دارند جدا می‌کند. پیش از هر ارسال، نسخه داخل پنل فروشنده را نیز بررسی کنید؛ قوانین قابل تغییر هستند.

## بسته و راهنما

- [ ] اجرای `./tools/build-release.sh` و نصب مستقیم ZIP داخل `dist/Plugin/` روی وردپرس تمیز
- [ ] وجود `dist/help.pdf` و بازبینی نگارشی و تصویری آن
- [ ] نبود ZIP تودرتو، `.git`، تست‌ها، graphify، ابزار build و فایل‌های محرمانه در ZIP مشتری
- [ ] یکسان بودن نسخه هدر، ثابت PHP، `Stable tag` و changelog
- [ ] تولید SDK با آخرین نسخه ابزار لایسنس راست‌چین؛ در صورت تغییر فایل، نام آن در `product-expiration-easy-peasy.php` و `includes/class-license-check.php` و hash آن در بلوک راست‌چین و `tools/build-release.sh` اصلاح شود
- [ ] پس از هر تغییر در `includes/class-license-check.php`، پیش از build آن را دوباره برای محافظت (ionCube) به راست‌چین بفرستید و نسخهٔ رمزگذاری‌شده را بدون باز کردن یا ذخیرهٔ دوباره در `protected/includes/class-license-check.php` بگذارید؛ این پوشه از PHPCS، phpcbf، `php -l`، فرمت‌کننده‌ها و هر جست‌وجو و جایگزینی بیرون است و هرگز نباید باز یا ویرایش شود
- [ ] بلافاصله پس از ارسال `includes/class-license-check.php` برای محافظت، `./tools/record-protected-source.sh` را اجرا کنید تا SHA-1 همان نسخهٔ ارسالی در `protected/includes/class-license-check.php.source-sha1` ثبت شود؛ اگر منبع بعد از آن تغییر کند، `tools/build-release.sh` ساخت بسته را متوقف می‌کند
- [ ] فایل `product-expiration-easy-peasy.php` هرگز برای محافظت فرستاده نشود؛ این فایل loader است و باید خوانا بماند
- [ ] بازسازی `help.pdf` از `docs/help-fa.html` پس از هر تغییر در راهنما

## آزمون فنی

- [ ] نصب تمیز و ارتقا از نسخه ۳.۱.۱
- [ ] PHP 8.1، 8.2، 8.3 و 8.4؛ ionCube متناظر و SDK سازگار با هر نسخه
- [ ] WordPress 7.0 و 7.1.3؛ WooCommerce 9.7 و نسخه پایدار جاری 11.2.1
- [ ] HPOS روشن و خاموش
- [ ] localeهای `fa_IR` و `en_US`؛ انتخابگر خودکار/شمسی/میلادی، ورود با ارقام فارسی/عربی/لاتین و کار با صفحه‌کلید در RTL/LTR
- [ ] ووکامرس غیرفعال، ionCube غیرفعال، فایل SDK مفقود یا تغییرنام‌یافته و لایسنس غیرفعال؛ هیچ‌کدام نباید Fatal بدهند (فایل SDK خراب را خود ionCube گزارش می‌کند)
- [ ] همین آزمون‌ها با ZIP نهایی که نسخهٔ محافظت‌شدهٔ `class-license-check.php` را دارد تکرار شود
- [ ] محصول ساده، متغیر، variation، Quick Edit، پاک‌کردن و تمدید تاریخ
- [ ] سه فیلتر فهرست، مرتب‌سازی، هر دو محل نمایش، سبد، سفارش و ایمیل text/html
- [ ] اجرای دستی و هم‌زمان cron، همگام‌سازی محصول والد و بازیابی موجودی قبلی
- [ ] اجرای `php tests/run.php` (شامل آزمون برابری جلالی PHP/JavaScript)، بررسی syntax فایل‌های JavaScript و PHPCS با `phpcs.xml.dist`
- [ ] اسکن ZIP نهایی در VirusTotal و ثبت نتیجه برای پرونده ارسال
