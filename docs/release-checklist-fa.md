# چک‌لیست انتشار در راست‌چین

این فایل مواردی را که به تصمیم انسانی، حساب فروشنده یا سرویس بیرونی نیاز دارند جدا می‌کند. پیش از هر ارسال، نسخه داخل پنل فروشنده را نیز بررسی کنید؛ قوانین قابل تغییر هستند.

## بسته و راهنما

- [ ] اجرای `./tools/build-release.sh` و نصب مستقیم ZIP داخل `dist/Plugin/` روی وردپرس تمیز
- [ ] وجود `dist/help.pdf` و بازبینی نگارشی و تصویری آن
- [ ] نبود ZIP تودرتو، `.git`، تست‌ها، graphify، ابزار build و فایل‌های محرمانه در ZIP مشتری
- [ ] یکسان بودن نسخه هدر، ثابت PHP، `Stable tag` و changelog
- [ ] تولید SDK با آخرین نسخه ابزار لایسنس راست‌چین و اصلاح hash در adapter در صورت تغییر فایل

## آزمون فنی

- [ ] نصب تمیز و ارتقا از نسخه ۳.۱.۱
- [ ] PHP 8.1، 8.2، 8.3 و 8.4؛ ionCube متناظر و SDK سازگار با هر نسخه
- [ ] WordPress 7.0 و 7.1.3؛ WooCommerce 9.7 و نسخه پایدار جاری 11.2.1
- [ ] HPOS روشن و خاموش
- [ ] localeهای `fa_IR` و `en_US`؛ انتخابگر خودکار/شمسی/میلادی، ورود با ارقام فارسی/عربی/لاتین و کار با صفحه‌کلید در RTL/LTR
- [ ] ووکامرس غیرفعال، ionCube غیرفعال، فایل SDK مفقود/خراب و لایسنس غیرفعال؛ هیچ‌کدام نباید Fatal بدهند
- [ ] محصول ساده، متغیر، variation، Quick Edit، پاک‌کردن و تمدید تاریخ
- [ ] سه فیلتر فهرست، مرتب‌سازی، هر دو محل نمایش، سبد، سفارش و ایمیل text/html
- [ ] اجرای دستی و هم‌زمان cron، همگام‌سازی محصول والد و بازیابی موجودی قبلی
- [ ] اجرای `php tests/run.php` (شامل آزمون برابری جلالی PHP/JavaScript)، بررسی syntax فایل‌های JavaScript و PHPCS با `phpcs.xml.dist`
- [ ] اسکن ZIP نهایی در VirusTotal و ثبت نتیجه برای پرونده ارسال

## فارسی‌سازی و ارائه

- [ ] دمو آنلاین فارسی و RTL بدون اطلاعات تماس شخصی
- [ ] بازبینی و درج متن فارسی اصیل آماده‌شده در `docs/rtl-theme-description-fa.md` (بیش از ۳۰۰ کلمه) در صفحه محصول
- [ ] تاریخ‌های قابل مشاهده در locale فارسی به‌صورت شمسی
- [ ] کاور ۲۱۰۰×۱۰۴۰ و آیکن ۳۲۰×۳۲۰، طراحی انسانی و بدون تصویر تولیدشده با AI
- [ ] تصاویر اصیل، خوانا و فاقد اطلاعات تماس یا برند شخص ثالث بدون مجوز
- [ ] حذف راه‌های ارتباطی خارج از راست‌چین از توضیحات، دمو و راهنما
